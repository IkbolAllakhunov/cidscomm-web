# Kidscomm

Адаптивный веб-сайт Kidscomm (платформа для детского сада: расписание,
медкарта, чат, фотогалерея) — React + Vite, mock-данные.

Открывается напрямую по ссылке в браузере — на телефоне и на ноутбуке.
Никакой установки, никакой привязки к Telegram не требуется.

## Запуск локально

```
npm install
npm run dev
```

## Деплой на Vercel

1. Залить этот проект в GitHub-репозиторий
2. Зайти на vercel.com → New Project → импортировать репозиторий
3. Framework Preset: Vite (определится автоматически)
4. Build command: `npm run build`, Output directory: `dist`
5. Deploy

После деплоя получишь обычную ссылку вида `https://kidscomm.vercel.app` —
её можно сразу давать родителям, учителям и директору детсада для входа
через браузер на любом устройстве.

## Структура

- `src/mock/` — тестовые данные и функции доступа к ним (заменим на API)
- `src/features/{parent,teacher,admin}/` — экраны по ролям
- `src/shared/` — общие компоненты, контекст пользователя
- `src/app/RootSwitcher.jsx` — определяет роль и показывает нужный интерфейс

## Адаптивность

Сайт должен корректно работать на всех размерах экрана — от небольших
телефонов до ноутбуков. Это активная задача разработки, см. `CLAUDE.md`
в корне проекта, раздел "Требование адаптивности".
